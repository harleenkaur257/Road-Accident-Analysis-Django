🔄 Data Processing Pipeline

The Road Accident Analysis System processes the Indian road accident dataset through Django and stores the records in a SQLite database. Django ORM is then used to retrieve, filter, aggregate and analyze the accident information.

Project Workflow

📄

Dataset

Indian road accident dataset containing 20,000 records.

🐍

Django Import

Dataset records are imported into the Django application.

🗄️

SQLite Database

Accident records are stored and managed using SQLite.

📊

Analysis

Django ORM retrieves and processes data for charts and insights.
