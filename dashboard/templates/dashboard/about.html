About the Project

The Road Accident Analysis System is a Django-based data analysis and visualization project designed to study Indian road accident data. The system stores accident records in a SQLite database and provides interactive analysis, accident hotspot mapping and database-driven insights.

📊 Project Overview

This project provides an interactive platform for exploring and understanding road accident patterns. Accident records are stored in the Django database instead of being processed directly from a CSV file.

  • Accident trend analysis
  • City-based accident analysis
  • Weather impact analysis
  • Road type analysis
  • Accident severity analysis
  • Vehicle involvement analysis
  • Risk score analysis
  • Geographical accident hotspot mapping

🎯 Project Objectives

  • Analyze patterns in Indian road accidents.
  • Identify accident trends across different cities and states.
  • Study the effect of weather conditions on accidents.
  • Analyze the relationship between roads, traffic and accident severity.
  • Study vehicle involvement and casualties.
  • Provide interactive visualizations for easier understanding of the dataset.
  • Provide geographical accident hotspot information.

💻 Technology Stack

Python

Main programming language used for the project.

SQLite

Django ORM

HTML & CSS

Used to create the dashboard interface and styling.

📊 Dataset Information

The project uses an Indian road accident dataset containing accident records and multiple attributes related to location, road conditions, weather, vehicles and severity.

20,000 Accident Records
24 Dataset Columns
2022–2025 Dataset Period
India Geographic Coverage

Important fields include Accident ID, City, State, Latitude, Longitude, Date, Time, Road Type, Weather, Visibility, Traffic Density, Cause, Accident Severity, Vehicles Involved, Casualties and Risk Score.
